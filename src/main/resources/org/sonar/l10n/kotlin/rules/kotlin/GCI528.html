The Android vibrator is a hardware actuator (motor or piezoelectric element) that consumes power every time it fires. Because its added value is often marginal compared to visual or audio cues, its usage should be avoided or minimised.

Avoid calling getSystemService(Context.VIBRATOR_SERVICE), getSystemService(Context.VIBRATOR_MANAGER_SERVICE), getSystemService(Vibrator::class.java), or getSystemService(VibratorManager::class.java). Prefer silent alternatives — visual feedback, badges, or quiet notifications — that deliver the same information without consuming extra energy.

Noncompliant Code Example

// API 26 — Vibrator (deprecated in API 31)
val vibrator = getSystemService(Context.VIBRATOR_SERVICE) as Vibrator  // Noncompliant
val vibrator2 = getSystemService(Vibrator::class.java)                 // Noncompliant

// API 31+ — VibratorManager
val vibratorManager = getSystemService(Context.VIBRATOR_MANAGER_SERVICE) as VibratorManager  // Noncompliant
val vibratorManager2 = getSystemService(VibratorManager::class.java)                         // Noncompliant

Compliant Solution

// Use visual feedback instead of haptic feedback
// Or notify via a quiet notification with no vibration pattern
