When rendering OpenGL content with GLSurfaceView, the default render mode is RENDERMODE_CONTINUOUSLY, which causes the view to redraw as fast as possible — even when nothing has changed on screen. This wastes GPU and CPU cycles and drains the battery unnecessarily.

Prefer RENDERMODE_WHEN_DIRTY: the view only redraws when GLSurfaceView.requestRender() is explicitly called, letting the GPU and CPU idle between frames.

Noncompliant Code Example

val surfaceView = GLSurfaceView(context)
surfaceView.setRenderMode(GLSurfaceView.RENDERMODE_CONTINUOUSLY) // Noncompliant
surfaceView.setRenderMode(1)                                     // Noncompliant

Compliant Solution

val surfaceView = GLSurfaceView(context)
surfaceView.setRenderMode(GLSurfaceView.RENDERMODE_WHEN_DIRTY) // Compliant
// Then trigger redraws explicitly:
surfaceView.requestRender()
