HTTP responses from URL.openConnection() can be cached on the filesystem via HttpResponseCache. When a response is reused from cache the network round-trip is avoided entirely, saving both energy and data. Without a cache every identical request repeats the full network path, draining the battery unnecessarily.

Call HttpResponseCache.install(cacheDir, maxSize) once at application startup (e.g. in Application.onCreate()) so all subsequent HttpURLConnection requests benefit from caching automatically.

Noncompliant Code Example

    // No cache configured — every request hits the network
    val connection = URL("https://api.example.com/data").openConnection()   // Noncompliant

Compliant Solution

    // In Application.onCreate():
    val cacheDir = File(cacheDir, "http_cache")
    HttpResponseCache.install(cacheDir, 10 * 1024 * 1024L)

    // Subsequent requests reuse cached responses automatically
    val connection = URL("https://api.example.com/data").openConnection()   // Compliant
