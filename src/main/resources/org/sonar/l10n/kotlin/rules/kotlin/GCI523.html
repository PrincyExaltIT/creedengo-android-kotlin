When calling LocationManager.requestLocationUpdates(), setting minTime to zero disables time-based filtering — the location provider sends updates as fast as it can, waking the device constantly and draining the battery. Use a positive value (e.g., 60 000 ms for once per minute) to let the hardware idle between updates.

Noncompliant Code Example

locationManager.requestLocationUpdates(
    LocationManager.GPS_PROVIDER,
    0L,    // Noncompliant — updates as fast as possible
    10f,
    listener
)

Compliant Solution

locationManager.requestLocationUpdates(
    LocationManager.GPS_PROVIDER,
    60_000L, // at most one update per minute
    10f,
    listener
)
