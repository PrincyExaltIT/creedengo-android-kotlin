In Jetpack Compose, Modifier.keepScreenOn() (available since androidx.compose.ui:ui 1.9.0) prevents the screen from dimming or turning off while the composable is in the composition. This is the declarative equivalent of android:keepScreenOn="true" in XML layouts (see GCI541).

Keeping the screen on continuously drains the battery. It should only be used for use-cases where the user actively watches the screen without touching it (e.g. video playback, navigation turn-by-turn, workout tracking). In all other cases the screen should be allowed to dim and lock normally.

Noncompliant Code Example

    Box(modifier = Modifier.keepScreenOn()) {   // Noncompliant
        Text("Hello")
    }

Compliant Solution

    // Remove keepScreenOn() and let the system manage screen timeout.
    Box {
        Text("Hello")
    }
