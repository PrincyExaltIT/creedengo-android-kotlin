Acquiring a WakeLock without a timeout keeps the CPU running indefinitely if the lock is never released (e.g. due to a crash or forgotten release() call), draining the battery excessively. Always prefer the overload that accepts a timeout in milliseconds.

Noncompliant Code Example

val wakeLock = (getSystemService(Context.POWER_SERVICE) as PowerManager)
    .newWakeLock(PowerManager.PARTIAL_WAKE_LOCK, "MyApp::MyTag")
wakeLock.acquire() // Noncompliant — no timeout

Compliant Solution

val wakeLock = (getSystemService(Context.POWER_SERVICE) as PowerManager)
    .newWakeLock(PowerManager.PARTIAL_WAKE_LOCK, "MyApp::MyTag")
wakeLock.acquire(10 * 60 * 1000L) // 10 minutes max
