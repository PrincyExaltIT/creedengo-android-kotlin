On Android 11 (API 30) and higher, calling Surface.setFrameRate() can change the physical display refresh rate. Rates above 60 Hz (e.g. 90 Hz or 120 Hz) cause the display hardware to refresh more frequently, which increases power consumption noticeably — even when app content is not changing at that pace.

Unless the content truly benefits from a higher refresh rate (e.g. a game with a stable high frame rate), keep the frame rate at 60 Hz or below by passing a value ≤ 60.0f as the first argument to Surface.setFrameRate().

Noncompliant Code Example

surface.setFrameRate(90f, Surface.FRAME_RATE_COMPATIBILITY_DEFAULT)   // Noncompliant
surface.setFrameRate(120f, Surface.FRAME_RATE_COMPATIBILITY_DEFAULT)  // Noncompliant

Compliant Solution

surface.setFrameRate(60f, Surface.FRAME_RATE_COMPATIBILITY_DEFAULT)   // Compliant
surface.setFrameRate(0f, Surface.FRAME_RATE_COMPATIBILITY_DEFAULT)    // Compliant — let the system decide
