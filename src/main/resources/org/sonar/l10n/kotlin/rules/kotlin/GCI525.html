With Bluetooth Low Energy (BLE), the advertising mode controls how frequently the device broadcasts its presence. Higher advertising frequencies consume significantly more battery.

When calling AdvertiseSettings.Builder.setAdvertiseMode(int), always use ADVERTISE_MODE_LOW_POWER (value 0) unless a lower latency is strictly required. Using ADVERTISE_MODE_BALANCED or ADVERTISE_MODE_LOW_LATENCY drains the battery faster.

Noncompliant Code Example

val settings = AdvertiseSettings.Builder()
    .setAdvertiseMode(AdvertiseSettings.ADVERTISE_MODE_LOW_LATENCY) // Noncompliant
    .build()

Compliant Solution

val settings = AdvertiseSettings.Builder()
    .setAdvertiseMode(AdvertiseSettings.ADVERTISE_MODE_LOW_POWER) // Compliant
    .build()
