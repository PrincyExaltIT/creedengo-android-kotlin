ListView, GridView, and RecyclerView render and hold all visible (and off-screen buffer) items in memory at once. Jetpack Compose lazy components — LazyColumn, LazyRow, LazyVerticalGrid, and LazyHorizontalGrid — compose only the items currently on screen, discarding items that scroll out of view. This reduces memory pressure, GPU work, and overall battery consumption, especially for long lists.

Noncompliant Code Example

    val list = ListView(context)       // Noncompliant
    val grid = GridView(context)       // Noncompliant
    val recycler = RecyclerView(context)  // Noncompliant

Compliant Solution

    // Jetpack Compose — items are composed only when visible
    LazyColumn {
        items(dataList) { item -> ItemRow(item) }
    }
