TelephonyManager.getDeviceId() returns the hardware device identifier (IMEI on GSM networks, MEID on CDMA networks). This identifier is permanent and cannot be reset by the user, which makes it unsuitable for tracking purposes and raises serious privacy concerns. It also requires the READ_PHONE_STATE permission.

Use Settings.Secure.ANDROID_ID instead: it is a 64-bit number unique to each combination of app-signing key, user, and device, and can be reset by a factory reset.

Noncompliant Code Example

val telephonyManager = getSystemService(Context.TELEPHONY_SERVICE) as TelephonyManager
val deviceId = telephonyManager.getDeviceId() // Noncompliant

Compliant Solution

val androidId = Settings.Secure.getString(contentResolver, Settings.Secure.ANDROID_ID)
