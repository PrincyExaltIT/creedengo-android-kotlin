The GPS sensor is expensive while in use. A common bug is to leave location updates running when the app enters an idle state (paused or stopped).

Calls to LocationManager.requestLocationUpdates() must be paired with LocationManager.removeUpdates(). Failing to do so can drain the battery in just a few hours.

Noncompliant Code Example

    val lm = getSystemService(LOCATION_SERVICE) as LocationManager
    lm.requestLocationUpdates(LocationManager.GPS_PROVIDER, 1000L, 1.0f, this)  // Noncompliant

Compliant Solution

    val lm = getSystemService(LOCATION_SERVICE) as LocationManager
    lm.requestLocationUpdates(LocationManager.GPS_PROVIDER, 1000L, 1.0f, this)
    lm.removeUpdates(this)  // Compliant
