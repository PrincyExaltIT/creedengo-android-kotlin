During a voice interaction session, VoiceInteractionSession.setKeepAwake(Boolean) controls whether the system holds a wake lock for the session while it runs a voice activity.

By default the system keeps the device awake. Calling setKeepAwake(false) releases that wake lock so the CPU can sleep, preventing unnecessary battery drain. Calling setKeepAwake(true) (or omitting the call entirely) keeps the device awake and wastes energy.

Noncompliant Code Example

    // Noncompliant — setKeepAwake never called (default keeps device awake)
    class MySession(ctx: Context) : VoiceInteractionSession(ctx)

    // Noncompliant — explicitly keeps device awake
    setKeepAwake(true)

Compliant Solution

    class MySession(ctx: Context) : VoiceInteractionSession(ctx) {
        override fun onReady() {
            setKeepAwake(false)   // Compliant
        }
    }
