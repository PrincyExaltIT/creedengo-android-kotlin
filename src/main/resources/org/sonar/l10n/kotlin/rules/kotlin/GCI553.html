WorkManager background tasks can be constrained to run only when the device battery is in a healthy state. Without battery constraints a task may execute even when the battery is critically low, accelerating discharge at the worst possible moment.

Add a Constraints object that calls setRequiresBatteryNotLow(true) and/or setRequiresCharging(true) and pass it to the work request via setConstraints().

Noncompliant Code Example

    // No battery constraint — runs regardless of battery level
    val workRequest = OneTimeWorkRequestBuilder<MyWorker>()   // Noncompliant
        .build()
    WorkManager.getInstance(context).enqueue(workRequest)

Compliant Solution

    val constraints = Constraints.Builder()
        .setRequiresBatteryNotLow(true)
        .build()

    val workRequest = OneTimeWorkRequestBuilder<MyWorker>()
        .setConstraints(constraints)
        .build()
    WorkManager.getInstance(context).enqueue(workRequest)
