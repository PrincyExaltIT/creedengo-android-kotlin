Creating a MediaPlayer object allocates resources (memory, codec instances). The class provides a release() method that must be called when the player is no longer needed to free those resources.

Failing to call release() can lead to continuous battery consumption on mobile devices as the underlying media engine keeps running.

Noncompliant Code Example

    val mp = MediaPlayer()   // Noncompliant — release() never called

Compliant Solution

    val mp = MediaPlayer()
    // ... use mp ...
    mp.release()             // Compliant
