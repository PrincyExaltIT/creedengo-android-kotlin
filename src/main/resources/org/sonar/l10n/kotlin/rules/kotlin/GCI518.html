Bluetooth Low Energy (BLE) is designed to provide significantly lower power consumption than classic Bluetooth. Its purpose is to save energy on both paired devices, but many developers default to the classic Bluetooth API without considering the BLE alternative.
Importing from android.bluetooth.le.* alongside android.bluetooth.* enables low-energy features and is considered good practice. Importing only from android.bluetooth.* (without android.bluetooth.le.*) is flagged as a missed optimisation opportunity.

Noncompliant Code Example

    import android.bluetooth.BluetoothAdapter  // Noncompliant — no BLE imports

Compliant Solution

    import android.bluetooth.le.BluetoothLeScanner  // Compliant — GCI518 fires positively
