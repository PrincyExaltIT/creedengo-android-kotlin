Importing com.google.android.gms.analytics.Tracker or com.google.firebase.analytics.FirebaseAnalytics means the app sends user behaviour data to Google Analytics. While not necessarily sensitive on its own, this is a first step towards Google Ads and user profiling — it should be declared and justified.

Noncompliant Code Example

    import com.google.android.gms.analytics.Tracker      // Noncompliant
    import com.google.firebase.analytics.FirebaseAnalytics  // Noncompliant
