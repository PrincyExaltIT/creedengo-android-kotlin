The flashlight (torch) is one of the most energy-intensive hardware components on an Android device. Turning it on programmatically via CameraManager.setTorchMode(cameraId, true) should be avoided unless absolutely necessary, as it causes a significant and sustained drain on the battery.

Noncompliant Code Example

val cameraManager = getSystemService(Context.CAMERA_SERVICE) as CameraManager
try {
    val cameraId = cameraManager.cameraIdList[0]
    cameraManager.setTorchMode(cameraId, true) // Noncompliant — turns torch on
} catch (e: CameraAccessException) {
    e.printStackTrace()
}

Compliant Solution

// Turn the torch OFF when done — passing false is compliant
cameraManager.setTorchMode(cameraId, false)

// Or avoid the torch entirely and use screen brightness for illumination
