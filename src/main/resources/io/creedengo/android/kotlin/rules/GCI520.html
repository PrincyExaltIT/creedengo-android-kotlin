Taking into account when the device is entering or exiting power save mode helps the app reduce its energy consumption accordingly. Two complementary approaches exist: monitoring the BATTERY_CHANGED broadcast by registering an IntentFilter on Intent.ACTION_BATTERY_CHANGED, or querying the current state programmatically with PowerManager.isPowerSaveMode().
This rule fires as a positive signal whenever either technique is already present in the code.

Compliant Code Example

    // Option 1 — broadcast receiver
    val filter = IntentFilter(Intent.ACTION_BATTERY_CHANGED)
    registerReceiver(batteryReceiver, filter)

    // Option 2 — programmatic check
    val powerManager = getSystemService(Context.POWER_SERVICE) as PowerManager
    val isInSaveMode = powerManager.isPowerSaveMode()
