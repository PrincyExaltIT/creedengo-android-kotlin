When calling LocationManager.requestLocationUpdates(), setting minDistance to zero disables distance-based filtering — the location provider sends updates even when the device has not moved, causing unnecessary wake-ups and battery drain. Use a positive value (e.g., 10 m) so updates are only delivered after meaningful movement.

Noncompliant Code Example

locationManager.requestLocationUpdates(
    LocationManager.GPS_PROVIDER,
    60_000L,
    0f,    // Noncompliant — updates even without movement
    listener
)

Compliant Solution

locationManager.requestLocationUpdates(
    LocationManager.GPS_PROVIDER,
    60_000L,
    10f,   // update only after 10 m of movement
    listener
)
