The camera is an expensive hardware component. Acquiring it via Camera.open() without subsequently calling Camera.release() keeps the camera hardware active unnecessarily, which can drain the battery in just a few hours and prevents other apps from using the camera.

Calls to Camera.open() must always be paired with Camera.release().

Noncompliant Code Example

    val camera = Camera.open()   // Noncompliant — release() never called

Compliant Solution

    val camera = Camera.open()
    // ... use camera ...
    camera.release()             // Compliant
