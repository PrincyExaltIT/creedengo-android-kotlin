Proactively wiping the application cache forces the operating system or the app itself to rebuild the cached content from the network or from disk. That rebuild burns extra CPU cycles, drains the battery and wastes bandwidth — all things eco-design rules try to avoid. Let the OS evict cache entries when it actually needs the space.

Noncompliant Code Example

val activityManager = context.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager
activityManager.clearApplicationUserData() // Noncompliant

context.cacheDir.deleteRecursively() // Noncompliant
applicationContext.cacheDir.deleteRecursively() // Noncompliant

Compliant Solution

// Don't clear the cache proactively. If you absolutely must remove
// a specific file (e.g. expired token, user logged out), target it precisely:
File(context.cacheDir, "expired-session-token").delete()
