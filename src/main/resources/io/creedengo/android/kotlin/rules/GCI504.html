Transmitting data over a network without compression consumes more energy than with compression. When data can be compressed by at least 10%, wrapping the output stream in a GZIPOutputStream reduces bandwidth and improves energy efficiency on both ends of the connection.

Any call to URLConnection.getOutputStream() that is not wrapped directly in GZIPOutputStream(...) is flagged.

Noncompliant Code Example

    val con = URL("https://example.com").openConnection() as HttpURLConnection
    val os = con.getOutputStream()                        // Noncompliant — uncompressed

    val os = BufferedOutputStream(con.getOutputStream())  // Noncompliant — not GZIP

Compliant Solution

    val os = GZIPOutputStream(con.getOutputStream())      // Compliant
