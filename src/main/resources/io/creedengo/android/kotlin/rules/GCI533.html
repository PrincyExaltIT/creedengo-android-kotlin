Good practice detected. To meet EU User Consent Policy requirements, Google provides a Consent SDK. Importing classes from com.google.android.ads.consent.* (deprecated legacy SDK) or com.google.android.ump.* (User Messaging Platform, recommended since Android API 21) signals that the app handles user consent properly.

This rule fires as a positive signal whenever either consent library is already in use.

Compliant Code Example

    import com.google.android.ump.ConsentInformation  // Compliant — GCI533 fires positively
