The rotation vector sensor (Sensor.TYPE_ROTATION_VECTOR) relies on a gyroscope in addition to an accelerometer and magnetometer, making it one of the more power-hungry sensor types. TYPE_GEOMAGNETIC_ROTATION_VECTOR provides a similar orientation estimate using only the accelerometer and magnetometer — no gyroscope — which significantly reduces energy consumption. It is noisier and better suited for outdoor use, but for most battery-sensitive applications it is the right trade-off.

When calling SensorManager.getDefaultSensor(int), pass Sensor.TYPE_GEOMAGNETIC_ROTATION_VECTOR (20) instead of Sensor.TYPE_ROTATION_VECTOR (11).

Noncompliant Code Example

val sensorManager = getSystemService(Context.SENSOR_SERVICE) as SensorManager
val sensor = sensorManager.getDefaultSensor(Sensor.TYPE_ROTATION_VECTOR)        // Noncompliant
val sensor2 = sensorManager.getDefaultSensor(11)                                // Noncompliant

Compliant Solution

val sensorManager = getSystemService(Context.SENSOR_SERVICE) as SensorManager
val sensor = sensorManager.getDefaultSensor(Sensor.TYPE_GEOMAGNETIC_ROTATION_VECTOR) // Compliant
