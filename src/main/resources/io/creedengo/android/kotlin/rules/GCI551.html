Services started with Context.startService() or Context.startForegroundService() continue running indefinitely until explicitly stopped. Forgetting to call stopService() or stopSelf() causes the service to drain the battery in the background without the user's knowledge.

Always pair every startService() call with a matching stopService() call (from the caller) or a stopSelf() call (from within the service) once the work is done.

Noncompliant Code Example

    // Service started but never stopped — Noncompliant
    startService(Intent(this, MyService::class.java))

Compliant Solution

    startService(Intent(this, MyService::class.java))
    // Later, when the work is complete:
    stopService(Intent(this, MyService::class.java))
    // Or from within the service itself:
    // stopSelf()
