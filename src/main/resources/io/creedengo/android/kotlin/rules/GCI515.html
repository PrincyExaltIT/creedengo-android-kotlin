Creating a MediaRecorder object allocates resources (memory, codec instances, hardware capture buffers). The class provides a release() method that must be called when recording is finished to free those resources.

Failing to call release() can lead to continuous battery consumption on mobile devices as the underlying recording engine keeps running.

Noncompliant Code Example

    val mr = MediaRecorder()   // Noncompliant — release() never called

Compliant Solution

    val mr = MediaRecorder()
    // ... record ...
    mr.release()               // Compliant
