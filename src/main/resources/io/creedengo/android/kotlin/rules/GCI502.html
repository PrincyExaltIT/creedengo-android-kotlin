Opening an internet connection inside a loop is extremely battery-inefficient: HTTP exchanges are among the most energy-consuming network operations. This typically occurs when a new connection is obtained by calling URL.openConnection() inside a for, while, or do-while loop body.
This pattern is also the root cause of polling — repeatedly fetching data at fixed intervals instead of using push notifications — which drains the battery unnecessarily.

Noncompliant Code Example

    for (endpoint in endpoints) {
        val conn = URL(endpoint).openConnection()  // Noncompliant
    }

Compliant Solution

    // Batch the work outside the loop, or use push notifications
    val conn = URL(endpoint).openConnection()
